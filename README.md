# פילאטיס – תרגול ועיוני

כלים ללימוד פילאטיס מתוך חוברות הקורס: תרגילים על 8 סוגי ציוד, שיעורים מודרכים, והחלק העיוני.

- **`index.html`** – אפליקציית התרגול: 8 סוגי ציוד, כרטיסיות, מבחן, עיון ו־8 שיעורים עם קול מדריך. נפתחת ישירות בדפדפן או דרך GitHub Pages.
- **`theory.html`** – החלק העיוני: 12 פרקים עם כרטיסיות, בוחן ושיעור מוקרא.
- **`חוברת-זיכרון.pdf`** – חוברת הזיכרון: תרגום שם, טריק לזיכרון, מוצא, נשימה, דגשים ושרירים לכל תרגיל.
